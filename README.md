# rpg-unicorn-platform

Base de arquitectura para construir mini-juegos RPG 2D estilo 8-bit con enfoque data-driven.

## Objetivo
- Separar motor reutilizable y contenido de juegos.
- Ejecutar en web (escritorio y móvil) con opción de despliegue como PWA.

## Estructura inicial
- `AGENT_CONTEXT/`: contexto operativo del agente.
- `docs/`: documentación funcional y técnica del proyecto.

## Estado
Repositorio en fase de definición de arquitectura y contratos iniciales.
